# Python Chess Game

A fully functional chess game developed using Python and Pygame.

## Features

* Complete chess piece movement
* Legal move validation
* Piece capturing
* Castling
* Pawn promotion
* Check and checkmate detection
* Draw detection
* Sound effects
* Graphical user interface

## Technologies Used

* Python 3
* Pygame

## Installation

Install the required library:

pip install -r requirements.txt

## Running the Game

Run the following command:

python chess.py

## Development

This project was developed as a personal programming project. AI assistance was used for code optimization, debugging, and improving documentation.
